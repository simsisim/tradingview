# Cumulative New Highs − New Lows (NYSE)

- TradingView script: `cumulative_nhnl.pine`
- StockCharts quick view: https://stockcharts.com/sc3/ui/?s=%21NEWHINYC-%21NEWLONYC
  (set Type = Cumulative, overlay SMA(10) or Parabolic SAR(1.0,1.0), add Price $SPX below)

Rule: cumulative line below its 10 SMA = risk off; above = risk on / buy the dip.
